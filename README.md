# Mo-zip
#  작품 배경
현재 대학생 및 일반인들이 동아리나 소모임을 탐색하고 참여하는 과정은 에브리타임, 카카오톡 오픈채팅, SNS 등에 흩어진 파편화된 정보들로 인해 불필요한 시간과 에너지를 소모하게 만듭니다. 또한, 잘 꾸며진 홍보글만으로는 모임의 실제 분위기나 활성화 정도를 객관적으로 파악하기 어려워 정보의 불투명성과 낮은 신뢰도 문제가 발생하고 있습니다. 더불어 구글 폼이나 개인 메시지 등 외부 도구를 활용한 비공식적이고 번거로운 지원 절차는 지원자에게 진행 상태 확인의 어려움을 주고, 운영진에게는 수많은 지원서를 일일이 수동으로 관리해야 하는 심각한 운영상의 비효율을 초래합니다.

# 작품 내용
본 프로젝트는 이러한 정보 탐색의 피로도와 운영의 비효율성을 근본적으로 해결하는 '통합 동아리 및 소모임 매칭·관리 플랫폼'을 개발하는 것을 목적으로 합니다. 흩어진 정보를 한곳에 모아 사용자 맞춤형 탐색과 필터링을 지원하고, 객관적인 지표로 투명한 정보를 제공하여 신뢰도를 높이고자 합니다. 나아가 지원서 제출부터 진행 상태 확인, 합격 통보까지 앱 내에서 한 번에 이루어지는 체계적인 관리 시스템을 구축하여, 지원자와 모임 운영진 모두의 편의를 획기적으로 개선하는 원스톱 솔루션을 제공할 계획입니다.
